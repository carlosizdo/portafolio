# Portafolio

Portafolio personal de **Carlos Izquierdo Gil**, desarrollador Full Stack (Python · Django REST Framework · PostgreSQL).

Hecho con HTML, CSS y JavaScript, sin dependencias ni paso de build.

## Ver en local

Abre `index.html` en el navegador, o sirve la carpeta:

```bash
python3 -m http.server 8000
```

y entra en http://localhost:8000.

## Publicación

Se publica con GitHub Pages desde la rama `main` en https://carlosizdo.github.io/portafolio/
