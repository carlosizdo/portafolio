# Imágenes del portafolio

Deja aquí las imágenes con estos nombres exactos y la web las usará sola, sin tocar el código:

| Archivo | Dónde se ve | Tamaño recomendado |
|---|---|---|
| `tfg.webp` | Portada del proyecto «Gestor de polideportivo» | 1200 × 760 |
| `securepass.webp` | Portada de «SecurePass» | 1200 × 760 |
| `campings.webp` | Portada de «Campings CV» | 1200 × 760 |
| `og-image.png` | Vista previa al compartir el enlace (LinkedIn, WhatsApp…) | 1200 × 630 |

Mientras una captura no exista, la tarjeta muestra el degradado con el icono de siempre.

El CV descargable va en la raíz del repositorio como `cv.pdf` (versión pública, sin teléfono).
